Usage: hydra-genetics create-rule [OPTIONS]

Options:
  -c, --command TEXT  command that will be run, will be used to name the rule
                      (with --script it is the full rule name)  [required]
  -t, --tool TEXT     tool that will be used to run the command, if provided
                      it will be used during the naming of the rule, e.g.,
                      samtools, optional. With --script it only selects the
                      .smk file and is not added to the rule name
  -m, --module TEXT   name of the module/pipeline where the rule will be
                      added. Expected folder structure is
                      module_name_or_pipeline/workflow/, the rule will be
                      added to a subfolder named rules, env.yaml to a
                      subfolder named envs.  [required]
  -a, --author TEXT   Name of the main author(s)  [required]
  -e, --email TEXT    E-mail(s) of the main author(s)  [required]
  -o, --outdir TEXT   Output directory where the module is located (default:
                      current dir)
  --script            create a rule that runs a Python script: the rule is
                      named after --command, --tool (if given) only selects
                      the .smk file, and stub workflow/scripts/<command>.py
                      and test_<command>.py are created
  --help              Show this message and exit.
